# /why-call — anchored critique (register: brand)

Pre-launch design evaluation sweep, Phase 1A. Anchored pass (blind pass already ran).
Evidence: Playwright (chromium headless) at 1280x900 and 390x844, EN + ES, plus 768 and 320
spot checks; computed styles, contrast math, keyboard focus traversal, network read.
Screenshots in scratchpad (`whycall-*.png`). Source: `app/[locale]/why-call/page.tsx`,
strings `messages/{en,es}.json` `why` namespace. Detector: `detect.mjs --json` on the page
file — exit 0, no findings.

## What the page is

A five-section "document on ruled paper": h1 (`text-h2-loud`, 800), ink-2 lede, five
`border-t border-line` sections, one green CTA to /bills. The one green thing on the page
is the one action — the color law observed to the letter.

## Nielsen scores (0–4), brand lens

1. **Visibility of system status — 3.** Desktop header marks "Why call?" active
   (`aria-current="page"` + ink fill, verified 1280 EN/ES). Title tag correct both locales.
   Deduction: on mobile the page has no presence in the thumb bar and no location mark of
   any kind — documented trade (Header.tsx:49–54), but a mobile reader has zero "you are
   here" signal.
2. **Match with the real world — 4.** The copy is the best object on the page: plain-words
   mechanics of congressional tallies, voicemail parity, "there's no debate." ES is written,
   not mirrored ("no un premio de consolación"). Nothing to deduct in either language.
3. **User control and freedom — 4.** Skip link first tabbable, locale switch preserves the
   route (/why-call ↔ /es/why-call), one exit, no traps, back always works.
4. **Consistency and standards — 4.** Fully token-set, computed-verified: h1 40px/-0.4px/800
   at 1280, 24px at 390 (clamp floor); h2 26→21; lede steps 18→21 exactly at the 62rem
   breakpoint (18 at 768, 21 at 1280 — never interpolates). One green action, ink headings,
   `line` used only as decoration.
5. **Error prevention — 4.** Static document; the content itself is error-prevention for the
   call (what to say, voicemail alternative, "the staffer is just writing down your position").
6. **Recognition rather than recall — 3.** "What do I actually say?" lists the five script
   components as prose the caller must remember later; the product's own script feature is
   never linked from the section. The single CTA routes through /bills (call-next funnel —
   deliberate), but at the exact moment the page creates the intention, the tool that removes
   recall is one unlinked step away.
7. **Flexibility and efficiency — 3.** Both locales, keyboard flow clean (verified traversal:
   skip → lockup → nav → CTA → footer). Deduction: at 48–64rem the page leaves the header nav
   (`wide: true`) and on phones it is footer-only — reachable, measured, documented, but the
   page's own discoverability rests on one footer link for most mobile users.
8. **Aesthetic and minimalist design — 4.** The ruled-paper conceit is executed exactly:
   every block's edges agree to the pixel at every viewport (392–888 at 1280; 16–374 at 390),
   one green object, zero ornament. As a brand surface it is quiet rather than spectacular,
   but the discipline itself is the distinctiveness — no generic component noise anywhere.
9. **Error recognition/recovery — 4.** No failable states exist on the surface (verified: no
   forms, zero console errors, zero failed requests both locales).
10. **Help and documentation — 3.** The page IS the product's documentation and mostly
    excellent. Deduction: it makes empirical claims — "Congress receives tens of millions of
    emails a year," "Reporting has documented offices overwhelmed… members shifting
    position" — with no citation anywhere, on a product whose footer trust column is
    literally "Citations" and "the official record." The one page that argues from evidence
    is the one page that cites none.

## Audit (0–4 each)

- **Accessibility — 4.** Computed: CTA white-on-go 6.43:1 (AA at 16px/700), lede ink-2
  7.87:1 (AAA), body 17.66:1. Focus: 3px ink ring offset 1px; `.ring-gap` swaps the border
  to paper so the ring never touches the fill (verified visually, es-1280/es-390 captures).
  Skip link present and first. Single h1, ordered h2s, `html lang` correct both locales.
  CTA 48px tall (298px wide EN, full-column ES mobile).
- **Performance — 4.** Network read (dev): doc 43KB, 26 requests, total 914KB of which
  793KB is dev-mode script — not representative; prod is SSG and was not built in this
  sweep (flagged). Surface-specific weight is effectively zero: no images, no third-party
  fonts, no page-specific JS, zero failed requests, zero console errors.
- **Theming/system fidelity — 4.** Two laws clean: green spent once on the one action, no
  amber anywhere, CTA `rounded-control` 8px (hand-sized), rules are `line` and decorative
  only, nothing is a pill. Detector: 0 findings.
- **Responsive — 3.** Zero horizontal overflow at 320/390/768/1280 in both locales. The
  deduction: the CTA has no vertical padding (`px-6` only, pt/pb computed 0px), so when the
  label wraps — ES at 390 (55px tall) and EN at 320 — the text block sits against the border
  with only half-leading air. It reads, but the wrapped state is under-inset.
- **Anti-patterns — 4.** `detect.mjs --json "app/[locale]/why-call/page.tsx"` → `[]`, exit 0.

## Findings

- **P2 · Unsourced empirical claims on a citations-first brand** — `messages/en.json` +
  `es.json`, `why.tallyBody` / `why.emailBody` (rendered app/[locale]/why-call/page.tsx:44).
  "Reporting has documented…" / "tens of millions of emails" carry no source links while the
  footer sells "Citations." Add 2–3 inline sources (t.rich) or a one-line sources note.
  decisionNeeded — owner picks the sources and whether links belong in this register. (M)
- **P3 · Script section doesn't hand you the script** — page.tsx:41–46 ("What do I actually
  say?"). Prose describes the five components; no link to the script flow. Single-CTA
  discipline may be deliberate. decisionNeeded. (S)
- **P3 · Wrapped CTA loses its inset** — page.tsx:50. Add `py-2` (on-scale) so the two-line
  ES-390/EN-320 state keeps vertical padding; min-h-12 still governs the one-line state. (S)
- **P3 · Double column cap contradicts its own comment** — page.tsx:36–37. `max-w-read` on
  both `article` and inner div; the file's comment says "capped ONCE." Harmless today
  (same token), but it is the exact per-block-cap pattern DESIGN.md's measure section exists
  to prevent. Drop one. (S)
- **P3 · DESIGN.md ladder drift** — DESIGN.md ladder table says `text-h2-loud` 26→40;
  globals.css:192 implements `clamp(1.5rem, 4vw, 2.5rem)` = 24→40 ("mobile-density pass
  2026-07-29"). This page's h1 renders 24px at 390, per code. Correct the table. (S)
- **P3 · No mobile location signal** — /why-call absent from the thumb bar (Header.tsx:49–54,
  documented and measured). Footer-only reachability + no active mark on phones. Deliberate;
  revisit only if the page matters more post-rename. decisionNeeded. (S)

## Strengths

- The copy: plain-language civic mechanics with real warmth, written natively in both
  languages — the strongest brand asset on the surface.
- Color-law discipline verified by computation, not eyeball: exactly one green object.
- Column-edge agreement to the pixel at every viewport — the measure token doing its job.
- Clean keyboard story: skip link, correct order, ring-gap focus on the filled CTA.
- Zero overflow 320→1280, both locales; zero console errors; zero failed requests.
