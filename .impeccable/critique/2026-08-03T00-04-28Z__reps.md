Two factual misses: multiDistrict note says "We've shown **both** below" while 841 ZIPs render 3–6 district sections (verified: /reps?zip=91711 renders six h2s over that exact sentence, EN and ES); the lede "Every US resident has one House representative and two senators" is false for DC/territories on the very page that corrects it three lines later.
3. **User control and freedom — 4.** Refinement is optional and escapable ("Show all districts for ZIP 10001", verified); every error keeps the form inline (never a dead end); bogus ?district=XX-99 degrades silently to the candidate list (verified); Change ZIP always present.
4. **Consistency and standards — 3.** Registers are disciplined (3px ink rule + uppercase label + role=alert for failure; 1.5px rule + wash for information — both verified rendered). Deductions: changeZip link is the only link on the page without min-h-11 (page.tsx:273, measured 111x17); vacant card lands in the last grid slot while an occupied House seat always renders first (76932: Cornyn, Cruz, then vacancy); ES h2 "Ya sabes a quién llamar." carries a period the EN twin lacks.
5. **Error prevention — 4.** inputMode=numeric + maxLength=5 + autocomplete=postal-code; client validation before nav; the FormData hydration-race fix (ZipForm.tsx:64-78); progressive enhancement GET action so the pre-hydration form still works; address form length check before any network.
6. **Recognition rather than recall — 4.** Saved ZIP prefills from localStorage; the empty state previews the exact payoff (three ghost cards + promise caption) before asking for anything; URLs carry full state (?zip, &district) so results are shareable/bookmarkable; district headings label every section.
7. **Flexibility and efficiency — 3.** tel: deep links, details-disclosure local offices (all rows measured 44px), container-query form works at every width it's embedded at. Deduction: a 6-district ZIP is a 4,182px page with no jump navigation between sections, and the answer to "which one is mine" (the refine form) scrolls away above the sections it disambiguates.
8. **Aesthetic and minimalist design — 3.** Ruled-paper register is exceptional discipline: one green per card, notes opened by rules not fills, page shape never changes. Deduction: split view duplicates full senator cards (dial and all) per district — 19% of ZIPs (6,458 two-district) show one duplicate pair; 91711 renders Gillibrand/Schumer-class duplication six times. 9. **Error recovery — 4.** Best-in-class: distinct plain-language messages for invalid/notFound/unavailable/rateLimited; the PO-box message explains *why* a valid ZIP can fail and offers three recovery paths; failure is tri-signal (3px rule + bold label + ARIA) with color deliberately third (go/alert are 1.19:1 apart — a deuteranope-safe stack, verified rendered in both locales).
10. **Help and documentation — 4.** "First call ever? Two minutes on why it works" in-flow; refinePrivacy explains the address's fate at the moment of the ask; delegate note teaches what a delegate can do; house.gov as the authoritative fallback in both error and vacancy paths.
