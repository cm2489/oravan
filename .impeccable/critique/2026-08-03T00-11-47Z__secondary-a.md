## Findings

### P0 — /about renders raw i18n keys in the operator/funding section (both locales)
`app/[locale]/about/page.tsx:43,50` calls `t('builtBy')` / `t('repoLinkLabel')` with `t = getTranslations('about')` (line 19), but the keys live under the **`privacy`** namespace (`messages/en.json:436-437`, `messages/es.json:436-437`). Rendered output on http://localhost:3000/about and /es/about is the literal text "about.builtBy about.repoLinkLabel" — the paragraph that names Colby Maxwell and links the public repo, sitting directly above the Stripe donation link. Two server MISSING_MESSAGE console errors confirm. Introduced by c76e7c4 (blind-sweep fixes, 2026-08-02): the page reference moved to /about but the keys were never moved. On /es the visible literals are the ENGLISH key paths — a double parity break. Fix (S): move both keys from `privacy` to `about` in **both** message files (grep confirms only about/page.tsx references them); consider a funnel-style invariant that no rendered page matches `/\b(about|privacy|common|citations|mcp|partners)\.[a-zA-Z]+\b/`.

### P2 — No copy affordance on the three copyable artifacts (decisionNeeded)
/mcp endpoint (`mcp/page.tsx:110-112`), client config (`:118-120`), /citations canonical URL (`citations/page.tsx:112-114`). The register these pages court (integrators, reporters) expects one-click copy; drag-selecting a `break-all` URL at 390px is fiddly. Costs a small client component on static pages — owner's call. (M)

### P2 — Three visual weights for the same act: "read the sibling policy" (decisionNeeded)
/mcp→privacy is a bordered button (`mcp/page.tsx:149-154`); /mcp→citations an underlined green link (`:208-213`); /citations→mcp a 14px inline link (`citations/page.tsx:98-106`). If the hierarchy is deliberate, fine — but the three patterns are close enough to read as drift. (S)

### P2 — /about carries no distinctive brand artifact (decisionNeeded)
Judged on the brand register: the identity page reads as a beautifully set terms page. The name-lore line is the only brand moment; the Stamp (also substantive: the printed sync date) or a specimen would give the one page a skeptical journalist screenshots a designed moment. Owner taste; the color/shape laws stay intact. (M)

### P3 — Tool-title span untagged on /es/mcp
`mcp/page.tsx:131`: the English `TOOL_INFO[name].title` span has no `lang="en"` while the description `dd` (line 133) is tagged — screen-reader pronunciation switch is incomplete on the ES route. (S)

### P3 — External links unannounced
`about/page.tsx:44-51` (repo) and `:66-73` (donate) open `target="_blank"` with no visually-hidden "opens in new tab" text. (S)

### P3 — Redundant inner `max-w-read` wrapper on all four pages
`about:28-29`, `partners:30-32`, `citations:89-91`, `mcp:100-102`: `div.max-w-read` inside `article.mx-auto.max-w-read` is a no-op cap; the "one cap on the column" comment is satisfied by the outer element alone. Hygiene only. (S)
